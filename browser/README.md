# Warrior's Paradise — Field Edition

## Real glTF skeletal rig + local PBR material atlas (October 2026)

The Cloudflare `/3d/` game now uses a **real skinned Kenney CC0 humanoid model** on nearby soldiers: 58 joints with inverse bind matrices, weighted vertex influences, hierarchical transforms, and gait/crouch poses. The implementation (`browser/3d/skinning.js`) also interprets simple LINEAR/STEP glTF animation channels when supplied. **This particular Kenney GLB contains no animation clips**; its poses are generated by our bone animation code. Near soldiers use the rigged mesh according to a graphics-tier cap, while farther soldiers or failed downloads use the established optimized original infantry geometry. A period-inspired helmet, webbing, packs and rifle are overlaid. The source character is a stylized survivor, not a faithful British or German 1944 uniform. Its content and exact original Git SHA1/SHA256 are pinned in `browser/3d/assets/kenney/CHARACTER_MANIFEST.json`.

**Texture pipeline:** the WebGL2 shader samples a locally generated **4-material atlas** (pasture, mud, limestone and brick) with albedo, tangent-like bump normal and roughness channels, rather than only flat material colors. Its source is `browser/3d/material-atlas.js`; the same shader has a low-tier fallback that bypasses atlas calculations for limited phones. The atlas is deterministic and generated on-device with no network. **These are not professionally photographed ambientCG PBR maps**; real measured/photographic material capture and physically accurate tangents remain separate future work.

**Recorded audio:** an optional small `cc0-gunshot.wav.b64` from `transitive-bullshit/ai-safety-doom` was composed from documented CC0 shotgun/airsoft pump recordings; its original creators and source are tracked in `browser/3d/assets/audio/MANIFEST.json`. Audio decoding occurs after deployment; failed downloads or WebAudio decoding simply keep the synthetic spatial sound. This is a **generic recorded gunshot layer, not authentic period Lee-Enfield/Sten/Bren recordings**. No third-party runtime service is needed.

**Regressions:** `browser_skinning_smoke.js`, `browser_material_atlas_smoke.js`, `browser_recorded_audio_smoke.js`, and the combined scene test cover source integrity, actual vertex deformation, texture upload and fallback. For full production realism we still need dedicated WWII meshes, detailed character texture assets and authentic animations/audio, material artist review, physical device profiling and graphical quality assurance.


## Tactical presentation and CC0 Quaternius farm update (October 2026)

The Cloudflare game now includes a period-informed **3D infantry and weapon presentation layer** (`browser/3d/battle-art.js`) and a new **spatial WebAudio sound engine** (`browser/3d/battle-audio.js`). Infantry visual poses vary with movement, direction, suppression and crouching, and three separately shaped first-person weapons distinguish the Lee-Enfield, Sten and Bren. Sounds are *original procedural synthesis* (weapon report, battlefield wind, distant fire, footsteps and nearby artillery); they are **not professionally recorded sound samples**. Audio starts only after deployment and has a mute control. Procedural terrain shading adds grass, masonry and brick variation plus atmospheric fog; it is **not a full PBR texture pipeline**.

**Genuine additional CC0 art:** 4 Quaternius Farm Buildings models (barn, chicken coop, windmill, well) are bundled alongside the existing 5 Kenney Nature models. The Quaternius GLBs are placed in the actual Normandy map, have simplified physical collision and line-of-sight occlusion, and are not fetched from a third party at runtime. Farm asset failure preserves the Kenney world; total asset failure preserves the original procedural level. The `browser/3d/assets/quaternius/MANIFEST.json` file pins license, creator, source SHA-256 and Git blob identities.

**Licensing:** Kenney and Quaternius source assets are CC0; all new authored game geometry and procedural sound code are original. No restricted Fab, Sonniss or questionable Sketchfab media is distributed. Inspect all attribution/provenance entries before public distribution.

**Still not shipped:** skinned and retargeted imported WWII character meshes and motion-captured clips; authentic licensed weapon meshes; photo-based terrain PBR normal/roughness/albedo maps; recorded cinematic explosions and Foley. These require a texture-capable glTF/skinning loader, source-file clearance, size optimization, and real-device QA. These should not be described as complete.

Tests: `node tools/tests/browser_visual_audio_smoke.js`, `node tools/tests/browser_quaternius_glb_smoke.js`, and `node tools/tests/browser_cc0_scene_smoke.js`.


## CC0 models in the Cloudflare 3D battlefield (October 2026)

The `/3d/` game now loads **five real glTF 2.0 mesh assets from Kenney Nature Kit (CC0)**: oak tree, pine, rock, bush and fence. They are bundled in `browser/3d/assets/kenney/` as canonical Base64 transport files containing the original unmodified GLB bytes. See `MANIFEST.json` for original artist, license, mirror and upstream Git blob hashes.

A small, auditable static GLB importer (`browser/3d/asset-loader.js`) extracts geometry from the models, places instances into the existing WebGL2 scene and draws them with a coherent Normandy palette. Trees block walking and firing sightlines through their trunks. This is an **actual imported 3D asset path**, not a screenshot or a placeholder citation.

The entire client and all its deployed model bytes are hosted on **Cloudflare Pages**. No third-party asset servers, API keys, graphics server, payments or CDN JavaScript are required at playtime. The existing service worker caches successfully fetched models for subsequent offline use. If downloading or decoding the optional art fails, the procedural battlefield remains playable.

**Important limitation:** this is a static mesh importer for curated, uncompressed glTF/GLB geometry and base-color materials. It is **not** a full GLTFLoader, and does not yet support skeletal animations, skinning, textured PBR materials, compressed geometry or animated soldier/weapon GLBs. Kenney's simple low-poly nature kit is legal foundation art rather than photorealistic foliage. High-fidelity military assets must be licensed individually and integrated through a proper textured/animated importer.

Run the offline binary integrity check: `node tools/tests/browser_cc0_glb_smoke.js` and the regular WebGL gameplay smoke. The integrity test verifies all geometry and checks that each committed GLB's Git object identity matches the recorded original source.

**A playable, lightweight browser skirmish for phones and low-power computers.**

This is deliberately a **separate implementation**, NOT the full Unreal Engine 5.8 game and not a streamed desktop build. It uses textured Canvas 2D raycasting and procedural art (still not full mesh-based 3D), with no WebGL dependency, Unreal Engine download, external JavaScript framework, paid backend, signup or account. Visuals, map, squad size and weapon fidelity are simpler than the UE project.

## Play from the repository

Easiest: open `browser/index.html` in a modern desktop browser. No server is required for the game logic.

With Python 3, from the repository root:

```bash
python tools/serve_field_edition.py
```

Then open `http://127.0.0.1:8000/`. This command serves **only** the `browser/` folder (not the whole private source tree).

To play on a phone connected to the **same trusted Wi-Fi** as the computer, run:

```bash
python tools/serve_field_edition.py --lan
```

Open `http://<COMPUTER-LAN-IP>:8000/` on the phone. If your OS firewall blocks port 8000, allow the local Python server on a **private network only**. This is local unencrypted HTTP, and does not automatically enable offline installation. For installability use the HTTPS Pages URL below. To stop, Ctrl+C.

## Browser controls

| Device | Controls |
|---|---|
| Desktop | WASD movement, **mouse horizontal/vertical look**, click/hold fire, **right-click ADS**, Shift sprint, R reload, F frag, T smoke, C crouch, V heal, Q squad-switch, X follow/hold orders, Esc pause |
| Phone/tablet | Left thumbstick moves; drag on the right to look **left/right/up/down**; FIRE, **hold ADS**, reload, frag, smoke, field dressing, switch soldier and follow/hold buttons |
| Any | Choose **Normandy Farm / Occupied Town / Forest Outpost**, **Assault / Last Stand**, Recruit / Regular / Veteran enemies, aim sensitivity and ECO / Balanced / Sharp / **Ultra** graphics. ECO remains default on touch devices |

In **Assault**, capture three sectors by occupying each flag after defeating defenders. In **Last Stand**, survive five progressively larger waves and obtain ammo, bandages and limited explosives between waves. Choose from three tile-layout battlefields. Your three-person squad uses Lee-Enfield / Sten / Bren roles and can provide finite-ammo covering fire; the medic can treat wounded allies. Enemy AI uses line-of-sight, recent-contact investigation, basic combat movement and reloading. The Field Edition is still a small single-player skirmish and **not** feature- or graphics-equivalent to World War Heroes.

## Offline install / home screen

On an HTTPS deployment (or localhost), the `manifest.webmanifest` and `sw.js` make static resources cacheable after the first successful visit. Use the browser's **Add to Home Screen** or **Install App** action if supported.

Opening `index.html` via `file://` plays locally but cannot register a service worker. LAN HTTP also does not normally qualify for service workers; use HTTPS or localhost. Refresh at least once online before expecting offline reuse. Incognito/private browsing can discard the cache.

## Relation to native Android / iPhone UE

The native UE 5.8 project is a **different** build. Epic supports Android packaging with a matching SDK/NDK, compatible phone graphics hardware and the mobile renderer. iPhone native packages require a macOS/Xcode signing workflow. The existing UE project has not yet been built or profiled for either phone platform; it should not be treated as a ready-to-install APK/IPA.

UE **Pixel Streaming** also permits phone/browser access to the full desktop edition, but requires a rendering PC or GPU cloud server, which is not provided by static free Pages hosting. The browser edition avoids that dependency by using its own lighter game simulation.

## Hardware honesty

- The browser edition is **CPU-first**, but the OS/browser may still use an integrated GPU for canvas composition. It does not require a discrete GPU.
- ECO targets ~225 internal horizontal pixels / 28 fps; Balanced ~330 / 35 fps; Sharp ~440 / 45 fps; Ultra ~640 / 58 fps. These are **configuration ceilings, not measured device FPS**. Canvas pixel budgets respect portrait/landscape ratio; a bounded adaptive scale lowers internal resolution when rendering cannot sustain its target. Procedural stone/timber textures, perspective grass/mud/road casting, tactical smoke and soldier billboards use Canvas 2D.
- Performance varies by device. If the browser or phone cannot run JavaScript Canvas 2D, it cannot play this game. Phones that support modern browsers generally can, but have not been device-tested here.
- This version is local single-player: no account, global multiplayer, or server synchronization. A static server cannot host the full native UE physics/AI simulation.

## Testing

The dependency-free Node runtime smoke command is:

```bash
node tools/tests/browser_runtime_smoke.js
```

It simulates portrait and landscape sessions and verifies ADS/fire/reload/grenade/squad controls, vertical touch look, each battlefield, Ultra rendering and a complete five-wave victory progression. It checks drawing operations, not actual image quality. It is **not** a real browser image review or phone performance benchmark.

The native Android plan is in [`docs/MOBILE_RELEASE_PLAN.md`](../docs/MOBILE_RELEASE_PLAN.md). The [mobile parity scorecard](../docs/MOBILE_PARITY_SCORECARD.md) compares actual functionality to the commercial reference and names the remaining acceptance tests.
